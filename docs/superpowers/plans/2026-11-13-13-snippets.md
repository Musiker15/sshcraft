# SSHCraft Teilplan 13: Snippets und Autovervollständigung Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Snippets in Paketen, die sich auf mehreren Hosts (neue Verbindungen oder offene Tabs) mit Standardzielen ausführen lassen, eine Seitenleiste im Terminal mit Snippets und Verlauf, und eine Autovervollständigung aus Verlauf, Pfaden, Snippets und bekannten Befehlen samt Argumenten, ohne KI.

**Architecture:**
- **Speicher:** Snippets und Verlauf liegen in der lokalen Datenbank (Schema 9). Der Verlauf ist mit dem Tresor versiegelt, weil Befehle Geheimnisse enthalten können (Spec Abschnitt 11).
- **Oberfläche:** Die Oberfläche verfolgt die getippte Zeile je Bereich selbst, schreibt fertige Befehle in den Verlauf und schlägt beim Tippen vor. Verlauf und Snippets kommen aus Rust, Befehle samt Argumenten aus einem festen Wörterbuch, Pfade über eine neue Verzeichnisabfrage der Sitzung: per SSH ein `ls` auf eigenem Kanal, lokal das Dateisystem.
- **Ausführen:** Snippets laufen in neuen Verbindungen als Starteingabe eines Workspace aus Teilplan 11, in offenen Tabs als Eingabe in die gewählten Bereiche.

**Tech Stack:** wie Teilplan 12, keine neuen Abhängigkeiten.

**Spec:** `docs/superpowers/specs/2026-11-11-sshcraft-design.md`:
- Abschnitt 2 "Terminal und Arbeitsfläche": "Seitenleiste im Terminal mit Snippets und Verlauf", "Autovervollständigung aus Verlauf, Pfaden, Snippets und bekannten Befehlen samt Argumenten, ohne KI".
- Abschnitt 2 "Snippets": "Snippets in Paketen (Ordnern), auf mehreren Hosts ausführen (neue Verbindungen oder alle offenen Tabs), Standardziele je Snippet, Snippets in der Autovervollständigung".
- Abschnitt 7: Sync umfasst Hosts, Gruppen und Schlüssel, Snippets und Verlauf gehören nicht dazu.
- Abschnitt 11: nichts Geheimes im Klartext auf der Platte.

## Global Constraints

- Alle Regeln der Teilpläne 1 bis 12 gelten weiter (Arbeitsbaum `G:\Claude\worktrees\sshcraft-t13`, Code Englisch, Commits Deutsch ohne KI-Zuschreibung, Gegenproben, lokal mergen, Texte nur über i18n, Fehler als `ErrorCode`).
- **Snippet:** `Snippet { id: SnippetId, name: String, package: String, content: String, default_targets: Vec<HostId> }`.
  - Name 1 bis 100 Zeichen ohne Steuerzeichen.
  - Paket 0 bis 100 Zeichen, leer heißt ohne Paket; Pakete sind nur Namen.
  - Inhalt 1 bis 10000 Zeichen, mehrzeilig erlaubt, sonst keine Steuerzeichen außer Tab.
  - Höchstens 50 Standardziele, höchstens 1000 Snippets.
- **Nur auf diesem Gerät:** Snippets synchronisieren nicht. Der Verlauf synchronisiert nie.
- **Verlauf:**
  - Je Bereich `scope`: `host:<uuid>` oder `local:<label>`; seriell kein Verlauf.
  - Höchstens 1000 Einträge je Bereich, gleicher Befehl rückt nach vorn (`uses` +1, `last_used`). Ein Befehl höchstens 2000 Zeichen.
  - Gespeichert als ein versiegelter JSON-Block je Bereich (`Vault::seal_secret`, Label `history:<scope>`). Ohne entsperrten Tresor wird nichts gespeichert und nichts vorgeschlagen.
  - Einstellung `history` (Vorgabe an), "Verlauf löschen" je Bereich und gesamt.
- **Kein Verlaufseintrag**, wenn:
  - die Zeile mit Leerzeichen beginnt;
  - die letzte Ausgabe eine Passwort- oder Passphrase-Abfrage war (`expectsInput`);
  - das Terminal im alternativen Bildschirm ist (vim, less);
  - Pfeil-, Tab-, Strg- oder Escape-Tasten die Zeile verändert haben (die getippte Zeile ist dann nicht sicher bekannt);
  - Broadcast an ist (nur im tippenden Bereich wird nichts doppelt erfasst).
- **Autovervollständigung** (Einstellung `autocomplete`, Vorgabe an):
  - Sie erscheint ab 2 Zeichen einer sicher bekannten Zeile, höchstens 8 Vorschläge.
  - Sie nimmt keine Taste weg, solange nichts gewählt ist. Pfeil nach unten wählt den ersten Vorschlag. Mit Auswahl wählen Pfeil hoch und runter, Tab oder Enter übernehmen, Escape schließt.
  - Übernommen wird nur das fehlende Ende. Ein Snippet, das nicht mit der Zeile beginnt, ersetzt sie über `Strg+U` (`\x15`).
  - Reihenfolge: Verlauf vor Snippets vor Pfaden vor Befehlen. Gleiche Texte erscheinen einmal.
- **Pfade:** Sie werden vorgeschlagen, wenn das aktuelle Wort mit `/`, `~`, `./` oder `../` beginnt oder `/` enthält.
  - Abgefragt wird `ls -1Ap -- '<dir>'` über einen eigenen Exec-Kanal (POSIX-Quoting, höchstens 500 Einträge, 64 KiB, 5 s), lokal `std::fs::read_dir` (nur absolute Pfade oder `~`).
  - Relative Pfade nur mit bekanntem Arbeitsverzeichnis (OSC 7). Antworten werden 10 s je Verzeichnis zwischengespeichert, Abfragen 250 ms entprellt.
- **Ausführen:** "Ausführen" tippt den Inhalt mit `\r` am Ende jeder Zeile, "Einfügen" ohne letztes `\r`. Zeilenenden werden zu `\r`.
  - Neue Verbindungen: ein Workspace-Tab mit einem Bereich je Host (höchstens 16, sonst mehrere Tabs), Titel `Snippet: <Name>`. Getippt wird nach dem ersten Verbinden wie die Starteingabe aus Teilplan 11.
  - Offene Tabs: die gewählten Bereiche mit Sitzung. Vorausgewählt sind die Standardziele beziehungsweise alle Bereiche, die mit einem Standardziel verbunden sind.

## Review Focus

1. **Geheimnisse im Verlauf:** Passwort an einer `sudo`-Abfrage, `mysql -p` mit Passwortabfrage, Zeile mit führendem Leerzeichen, Eingabe in vim. Erwartet: nichts davon landet im Verlauf, und auf der Platte steht nichts im Klartext. Tests in Task 1 und 3.
2. **Unsichere Zeile:** Tab-Ergänzung der Shell, Pfeil hoch, Strg+R, eingefügter Text mit Zeilenumbruch. Erwartet: keine falschen Einträge, keine Vorschläge für eine Zeile, die anders ist als die angezeigte. Tests in Task 3.
3. **Pfadabfrage mit feindlichen Namen:** Verzeichnis mit `'`, `$(...)`, Leerzeichen, Zeilenumbruch im Dateinamen. Erwartet: kein Befehl wird eingeschleust, Namen mit Zeilenumbruch werden ausgelassen. Tests in Task 2.
4. **Ausführen auf vielen Hosts:** 20 Hosts als Ziel, gelöschter Host in den Standardzielen, Bereich ohne Sitzung. Erwartet: zwei Tabs (16 und 4), der gelöschte wird übersprungen und gemeldet, kein Schreiben an fehlende Sitzungen. Tests in Task 4.
5. **Autovervollständigung stiehlt keine Tasten:** Pfeil hoch für den Shell-Verlauf, Tab für die Shell-Ergänzung ohne Auswahl, Enter ohne Auswahl. Erwartet: alles geht unverändert an die Shell. Tests in Task 3 und 5.

- Produces:
